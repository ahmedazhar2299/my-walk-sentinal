# v0.1.0-manuscript

Initial manuscript release of the IMU-based stroke mobility analysis code.

Includes:
- Feature extraction workflows for walking, turning, and sit-to-stand tasks
- XSENS and Vicon agreement analysis
- Home smartphone repeatability analysis
- Scripts and notebooks used to generate manuscript tables and figures

Notes:
- Raw or identifiable participant data are not included.
- Example or de-identified feature tables should be shared only when approved.
- Laboratory ICC values evaluate agreement with Vicon reference measures.
- Home ICC values evaluate repeatability across repeated smartphone recordings.
