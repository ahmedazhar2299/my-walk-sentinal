# Sample data

This folder contains synthetic sample data for smoke-testing the MyWalkSentinel reproduction workflow. The files are not participant recordings and should not be used for scientific interpretation. They only mirror the expected folder layout and CSV columns.

Contents:

- `home_smartphone/`: small smartphone-style home recording dataset with two SRS participants and two recording dates.
- `lab/XSENS_synchronized/`: small XSENS-style laboratory dataset with walking, left turn, right turn, and sit-to-stand folders.
- `lab_reference/`: small Vicon-style annotation CSVs for testing agreement-table loading.
- `subjects_sample.json`: sample SRS-to-smartphone mapping file.

Replace these folders with approved study data to reproduce the manuscript analyses.
